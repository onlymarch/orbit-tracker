# 위성 궤도 관측소 · Orbit Tracker

**[웹앱 바로 열기](https://onlymarch.github.io/orbit-tracker/)**  
접속 주소 `https://onlymarch.github.io/orbit-tracker/`

지구상의 한 지점과 시각을 선택하면, 지정한 **지상 반경과 최대 고도**를 모두 만족하는 인공위성을 지도에서 확인할 수 있습니다. 위성 하나를 선택해 이동 방향, 지상속도, 한 바퀴의 지상 경로를 살펴볼 수 있습니다. 데스크톱과 모바일 브라우저에서 설치 없이 실행됩니다.

## 처음 사용하기

1. 앱을 열고 **현재 위치 사용**을 허용합니다. 위치 권한 없이도 위도·경도를 직접 입력하거나 **관측점 지정**을 누른 뒤 지도를 탭할 수 있습니다.
2. 기본값인 **지상 반경 500km, 최대 고도 1,000km**로 시작합니다. 예를 들어 서울을 지정하면, 해당 시각에 위성 바로 아래의 지점(직하점)이 서울에서 500km 이내이고 위성 고도가 1,000km 이하인 위성을 찾습니다.
3. 지금 통과 중인 위성은 **기준 시각 한 순간**, 곧 지나갈 위성은 **이후 10분** 또는 **이후 30분**을 선택합니다. 시각은 화면에 표시된 기기 시간대를 따릅니다. 입력값을 변경한 뒤 **관측 조건 적용**을 누릅니다.
4. 지도의 화살표나 **통과 목록**의 위성을 선택합니다. 상세정보를 열어도 지도 중심과 배율이 유지됩니다. 한 바퀴를 한눈에 보려면 **지도에서 한 바퀴 보기**를 누릅니다.

**동작을 바로 확인하려면** 궤도자료에서 **ISS 과거 통과 예제**를 누르세요. 2024년 5월 6일(UTC)의 ISS 궤도자료와 당시 직하점이 자동 입력됩니다. 예제는 별도의 다운로드 없이 작동합니다. 현재 위치에서의 추적으로 돌아가려면 **운용 위성 불러오기 → 현재 위치 사용**을 누르고, 기준 시각을 비운 뒤 원하는 반경·고도와 **기준 시각 한 순간**을 적용하세요.

## 지도 조작

| 할 일 | 데스크톱 | 모바일 |
|---|---|---|
| 지도 이동 | 마우스로 드래그 | 한 손가락으로 드래그 |
| 확대·축소 | 마우스 휠 또는 ＋·− 버튼 | 두 손가락을 벌리거나 모으기 또는 ＋·− 버튼 |
| 관측 위치 변경 | 지도 우클릭 또는 **관측점 지정** 후 클릭 | **관측점 지정** 후 원하는 지점 탭 |
| 위성 상세정보 열기 | 위성 표식이나 목록 클릭 | 위성 표식이나 목록 탭 |
| 지도·목록·설정 간 이동 | 지도 옆 설정과 아래 목록 이용 | 상단의 **지도 / 통과 목록 / 관측 설정** 이용 |

**국가·기관 강조**는 선택한 소유 국가·기관의 위성에 주황색 사각 표식을 붙입니다. 다른 위성도 함께 표시합니다. **스타링크 위성 제외**를 체크하면 카탈로그 이름으로 식별한 스타링크를 계산과 표시에서 제외합니다.

## 궤적 읽기

| 표시 | 의미 |
|---|---|
| 점선 원 | 관측점을 중심으로 설정한 지상 반경 |
| 화살촉과 꼬리 | 화살촉은 진행 방향, 꼬리는 표시 시각 직전 5분의 직하점 경로. 꼬리의 점은 1분 간격 |
| 흰 원 | 선택한 위성의 직하점 |
| 보라색 실선과 점선 | 선택 시각을 기준으로 실선은 과거 반 바퀴, 점선은 미래 반 바퀴의 예측 지상 경로 |

상세정보의 **지상속도(km/s)**는 직전 15초 동안 직하점이 지표를 따라 움직인 평균 속도입니다. 위성 자체의 궤도 속도와는 값이 다릅니다. 지도 축척은 위도에 따라 달라지므로 위성 간 속도를 비교할 때는 상세정보의 수치를 사용하세요.

## 자료 출처와 계산 기준

- **위치·고도** — CelesTrak 운용 위성 GP 궤도요소를 satellite.js의 SGP4 모델로 전파해 계산합니다. 고도는 WGS84 기준타원체 위의 높이입니다. [CelesTrak GP 자료 설명](https://celestrak.org/NORAD/documentation/gp-data-formats.php) · [satellite.js](https://github.com/shashwatak/satellite-js)
- **소유 국가·기관** — NORAD 카탈로그 번호로 SATCAT의 소유 코드(`OWNER`)를 연결합니다. 과거 시각을 조회해도 소유 정보는 불러온 카탈로그 기준입니다. [SATCAT 필드 설명](https://celestrak.org/satcat/satcat-format.php) · [소유 코드 목록](https://celestrak.org/satcat/sources.php)
- **운영기관·용도·사진** — 확보된 임무 자료를 표시하고, 일반 위성은 NORAD 번호로 Wikidata를 조회합니다. **관련 사진 찾기**에서 NASA와 Wikimedia Commons를 검색할 수 있습니다. 검색 결과에는 지구 촬영 영상·발사 사진·상상도도 포함되므로 원본 설명과 이용 조건을 확인하세요. [NASA 이미지 자료실](https://images.nasa.gov/) · [Wikimedia Commons](https://commons.wikimedia.org/)
- **배경 지도** — Natural Earth 국가 경계를 HTML에 포함해 별도의 지도 타일 다운로드 없이 그립니다. [Natural Earth](https://www.naturalearthdata.com/)

현재 시각의 한 순간 모드는 약 3초마다 위치를 다시 계산합니다. 10분·30분 탐색은 5초 간격으로 계산하므로 짧은 통과를 놓칠 수 있습니다. 구간 지도에서 각 위성은 **해당 통과 중 관측점에 가장 가까웠던 표본 시각**에 표시되므로 위성마다 표시 시각이 다를 수 있습니다.

탐색 구간의 시작이나 끝이 궤도요소 기준시각에서 14일을 넘으면 해당 위성은 제외됩니다. 표시 위치는 궤도 예측값이며, 탐색 결과만으로 관측지에서의 육안 가시성을 판단할 수 없습니다.

## 결과가 비거나 연결이 끊길 때

- **통과가 0건이면** 자료 수신 상태와 ‘시각 범위 제외’ 개수를 확인하세요. 사용할 수 있는 자료가 있다면 탐색 구간을 30분으로 늘리거나 반경·고도 제한을 넓혀 보세요.
- **온라인 자료 수신이 실패하면** 저장된 자료가 있을 때 이를 사용합니다. 직접 내려받은 GP 자료는 **JSON 열기**, 소유 정보는 **소유 자료 열기**로 불러올 수 있습니다. [운용 위성 GP JSON](https://celestrak.org/NORAD/elements/gp.php?GROUP=active&FORMAT=json) · [운용 위성 SATCAT JSON](https://celestrak.org/satcat/records.php?GROUP=active&FORMAT=json)
- **특정 위성이 미확인으로 표시되면** 해당 항목의 소유·임무 자료가 있는지 확인하세요. 사진이나 운영기관 자료가 없어도 유효한 궤도요소가 있으면 위치 계산은 가능합니다.

## 로컬 실행과 배포

소스는 단일 [index.html](./index.html)입니다. 파일을 내려받아 브라우저로 열면 되며 빌드 단계는 없습니다. 브라우저가 로컬 파일의 위치 접근을 제한하면 지도를 눌러 관측점을 지정하세요. 최신 목록과 외부 사진 조회에는 인터넷 연결이 필요합니다.

개발본은 `main`, GitHub Pages 공개본은 [gh-pages 브랜치](https://github.com/onlymarch/orbit-tracker/tree/gh-pages)의 루트에서 제공합니다. 앱을 수정한 뒤에는 공개할 `index.html`을 `gh-pages`에도 반영하고 [배포 실행 결과](https://github.com/onlymarch/orbit-tracker/actions)를 확인하세요.
